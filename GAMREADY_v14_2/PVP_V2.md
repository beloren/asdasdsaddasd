# PvP v2 — шкала оглушения, рагдолл, парирование, награда за голову

## Как играется
- Удар киркой по игроку заполняет шкалу над его головой (4 деления). HP больше не снимается и тележка в руках не ломается.
- Сколько ударов на полную шкалу — по тиру кирки: T1-2 → 4, T3-6 → 3, T7-9 → 2. Пасс DoubleDamage ускоряет, DoubleHealth жертвы — замедляет.
- Полная шкала → **рагдолл** на 2.2 с: тело обмякает, отлетает от удара, над головой «STUNNED!». Вылетает **1 руда — самая дорогая** (сначала кусок в руках, потом ручной перенос, потом тележка). Потом 3 с неуязвимости (шкала полупрозрачная).
- Без ударов 4 с шкала плавно спадает — можно отбежать и «остыть».
- **Парирование** только встречными ударами: если оба замахнулись друг на друга в окне 0.3 с — «CLASH!», оба отлетают, очко соперника в этом обмене возвращается. Отдельной кнопки блока нет, рывка нет.
- **Награда за голову**: у игрока с тележкой, заполненной ≥70%, под шкалой маленький значок «💰 $X» (15% стоимости тележки). Кто уронит его в рагдолл — получает X. Один раз, пока тележка снова не опустеет.
- **Комбо** у атакующего: «x2, x3 HITS» справа, «KNOCKDOWN!» с добычей и наградой по центру.

## Интерфейс — через билдер
1. Rojo-синк, затем выполнить `tools/BuildCombatUI.lua` в Command Bar → появится `StarterGui/CombatUi`.
2. Правь вид мышкой: `StaggerTemplate/Bar/PipTemplate` (деление), `StaggerTemplate/State`, `StaggerTemplate/Wanted` (в `Wanted/Icon` можно поставить картинку мешка), `ComboCounter`, `Popup`. Имена не меняй.
3. Без билдера игра не ломается: клиент соберёт тот же интерфейс сам (`Shared/CombatUiBuilder`).

## Настройки — `Config.Stagger`
`PlayerHitsDealDamage = true` вернёт старый урон по HP поверх шкалы. Там же: удары по тирам, длительность рагдолла/неуязвимости, сила отлёта, окно парирования, порог и доля награды.

## Файлы
- `src/server/Services/CombatService.lua` — логика (блок «PVP v2»).
- `src/client/StaggerFX.client.lua` — шкалы, свой рагдолл, комбо, надписи.
- `src/shared/CombatUiBuilder.lua`, `tools/BuildCombatUI.lua` — интерфейс.
- `CartService:RemoveMostValuable`, `HandCarryService:RemoveMostValuable` — «самая дорогая руда».
- Квесты: «DEAL N DAMAGE» считают урон кирки за удар; «DIE 3 TIMES» → «GET KNOCKED DOWN 3 TIMES».
