# ФИЧИ v8 — престиж на очках, сундуки, динамит, мини-игра валунов, гоблинский рейд, баффы скинов

Все числа — в `src/shared/Config.lua`, блок «ФИЧИ v8» в конце файла.

## Что сделать в Studio (обязательно)

1. **Rojo-синк**, затем в Command Bar по очереди выполнить билдеры:
   `tools/BuildBoulderGameUI.lua`, `tools/BuildGearUI.lua`, `tools/BuildSkinUIv3.lua`, `tools/BuildPerkUI.lua`
   (и `tools/BuildCombatUI.lua` из v7, если ещё не запускали).
   Без билдеров всё тоже работает — клиенты строят интерфейс сами, но править мышкой будет нечего.
   Старое меню скинов (`BuildSkinUI*.lua` прошлых версий) больше не нужно — новое его заменяет.
2. **Лагерь гоблинов**: `Workspace/GoblinCamp/Zone` (невидимый Part — границы зоны, Anchored, CanCollide=false)
   и `Workspace/GoblinCamp/Spawns/*` (любое число Part-точек). Нет лагеря — рейд просто не запускается (warn в консоли).
3. **Модели сундуков**: `ReplicatedStorage/Assets/Chests/Chest_Common`, `Chest_Rare`, `Chest_Epic`, `Chest_Legendary`
   (часть с именем `Lid` будет откидываться при открытии). Нет модели — цветной ящик-заглушка.
   Опционально: `ReplicatedStorage/Assets/PrestigeCase` (чемоданчик) и `ReplicatedStorage/Assets/Dynamite`.
4. **Дев-продукты пропуска таймера сундуков**: создать 4 продукта и вписать ID в
   `Config.Chests.Types.<Rarity>.SkipProductId` (сейчас 0 — кнопка SKIP скрыта). Цена для подписи — `SkipRobux`.
5. Иконки слотов снаряжения (необязательно): атрибуты `Icon_Dynamite`, `Icon_Chest_*` на `StarterGui/GearUi`.

## 1. Престиж на очках (`PrestigeService.lua`, `PerkUI.client.lua`)
- Лимитов на пещеру больше нет. Престиж открыт с пещеры `Config.Prestige.MinCave` (8),
  стоит `CostCarts` (3) полные тележки текущей пещеры.
- Даёт очки: пещера 8–9 → 1, 10–11 → 2, 12–13 → 3, 14 → 4, 15 → 5. Множители ребёртов убраны.
- Чемоданчик рядом с NPC ребёрта → окно из 10 перков (Money, Luck, Mutations, Cart Space, Swift Feet,
  Safe Income, Geode Finder, Treasure Nose, Demolition, Head Start). Каждый качается многократно,
  цена уровня `floor(CostBase + level × CostGrowth)`. Перки не сбрасываются никогда.
- Старые игроки: каждый бывший ребёрт = 1 очко (одна миграция, флаг `PerksMigrated`).

## 2. Сундуки (`GearService.lua`, `GearHud.client.lua`)
- Падают с валунов (шанс × качество мини-игры × перк/скин удачи сундуков) и за зачистку рейда.
- Лежат в панели снаряжения слева. Взял в руку → клик по земле своей базы → стоит, идёт таймер
  (30с / 2м / 5м / 10м), таймер идёт и оффлайн. До 3 одновременно.
- Лут: деньги в долях тележки, жеоды, динамит, баффы, очко престижа (Legendary) и **скины — очень редко**
  (≈0.6% из Common … ≈22% из Legendary, а Legendary падает с шансом 0.2%).
- Скины больше не падают из валунов напрямую — их 7.5% ушли в деньги.

## 3. Динамит (`GearService.lua`, вкладка SUPPLIES у Experienced Miner)
- Покупка: 4-я карточка магазина улучшений, BUY x1 / BUY x5, цена = 0.35 тележки.
- В руку — клавиша G или слот слева. Клик по валуну — ставится (2 с), клик в другое место — бросок (кулдаун 6 с).
- Взрыв ломает валуны (в т.ч. на 2–3 тира сильнее кирки — только так их и можно сломать),
  игроков рядом кидает в рагдолл на 1 с и выбивает 1 руду. Безопасные зоны и щит защищают.

## 4. Мини-игра валунов (`RockService.lua`, `BoulderGameUI.client.lua`)
- Первый удар киркой открывает полосу справа от камня; клик/тап/пробел = удар: MISS / GOOD / PERFECT.
- Ударов нужно: валун на 1 тир слабее — 3, равный — 5, на 1 сильнее — 10, на 2+ слабее — с одного удара,
  на 2+ сильнее — только динамит.
- Итог по средней оценке: PERFECT BREAK (деньги ×1.6, +1 ролл, сундуки ×2.5) / GOOD / ROUGH (деньги ×0.6).
- Бить могут несколько игроков сразу — прогресс общий, награда каждому по его качеству.
- Защита от читов: сервер сам знает, где был бегунок, и принимает позицию клиента только в окне пинга.

## 5. Гоблинский рейд (`GoblinService.lua`)
- Дорожные волны выключены (`DisableRoadWaves`); обучающая волна у слайма осталась для гайда.
- Раз в 5 минут (предупреждение за 20 с) — рейд одного из типов: Thieves, Brutes, Shamans (лечат своих),
  Bombers (взрываются на игроке — рагдолл), Golden Boss (редкий).
- Гоблины никогда не выходят из зоны и не преследуют за её пределы — атакуют только тех, кто внутри.
- Лут с каждого гоблина — последнему ударившему; за зачистку — сундук по доле урона (Epic/Rare/Common,
  за босса лучшему — Legendary). Не зачистили за 3 минуты — гоблины уходят.

## 6. Баффы и дебаффы скинов (`Config.SkinBuffs`, `SkinUI.client.lua`)
- У каждой из 18 кирок 2 плюса и 1 минус: цена руды, удача, мутации, скорость, PERFECT-зона,
  сила удара по валуну, PvP-сбивание/стойкость, удача сундуков, сила динамита, урон по гоблинам.
- Новое меню: карточки → экран скина с ▲ зелёным и ▼ красным → EQUIP / UNEQUIP.
