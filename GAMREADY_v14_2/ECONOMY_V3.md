# Экономика v3 — что поменялось

Все файлы компилируются (`luau-compile -O0`), `Config.lua` проверен исполнением в Luau.

## Числа
- Руда: Coal $2 … Singularity $2000 (`Config.OreChain`, `Crystal_BaseValue = 1`).
- 15 пещер (модели Mine_Tier1..15). Окно — 5 руд, сдвиг на 1 за пещеру; пещера 15 = руды 14..18 с «богатыми» весами (`Config.TopCaveWeights`).
- Комбо тележки: только от заполнения, максимум x3 (`Config.Cart.ComboThresholds`).
- Единая «линейка» дохода: `Config.CartValue`, `Config.IncomePerMinute`, `Config.TripMinutes`. От неё считаются паки, пассивка, жеоды, валуны, гоблины, квесты.

## Прокачка (Б2)
- Пещера — главная ветка, 14 шагов (220 → 2.2M). Тележка/кирка — перки по 8 шагов, без капа ребёрта и без «отрыва веток».
- Ребёрт: нужна только пещера на капе. Кап 5 → +2 за ребёрт → 15. Цена 4.1K × 3.4 за ребёрт (≈3 тележки). Слайм — только бонус. Сбрасывается всё; острова остаются.
- Ориентир без пассов: пещера 5 (первый ребёрт) ≈ 30 мин, пещера 15 ≈ 6 ч чистой игры (с множителями ребёрта быстрее).

## Редкость (Ж2)
- Редкость = слот руды в текущей пещере: Common 60 / Uncommon 28 / Rare 9 / Epic 2.5 / Legendary 0.5 (`Config.OreRarityFor`).
- Над головой вместо редкости — цена куска, цвет = редкость (`HeldOreValue`).
- Вход шахты светится по прогрессу пещеры (1-3 Common … 13-15 Legendary), хорошая мини-игра +1 ступень.

## Монетизация (Е2)
- Кэш-пассы: x2 → x3 → x5, действует старший (`Config.CashPassMode = "Highest"`). x8 скрыт, у владельцев = x5.
- **Сделай в Creator Dashboard:** переименуй QuadCash → «x3 Cash», SextupleCash → «x5 Cash».
- Деньги-паки: 15/45/100 минут твоего дохода, стартовый — 60 минут (`Config.MoneyPackAmount`).

## Дроп и пассивка
- Жеоды: деньги = 0.4 / 1 / 3 тележки «родной» пещеры жеоды. Валуны: 0.6 тележки. Гоблины: 0.4–0.9 тележки.
- Пассивка: `CartShare` кристалла × доход в минуту (Quartz 2.5% … Titanheart ~29%). Сейф — 3 часа, оффлайн до 8 ч.
- Квесты/ежедневки/промокоды/слайм/острова (250 / 1.5K / 5K)/печь (слиток x10) — пересчитаны.

## UI
- Магазин улучшений — новое окно `UpgradeShopV3` (строится кодом, как у Island Keeper): вертикальные карточки → экран «было → станет» → UPGRADE / BACK. Старый ScreenGui `UpgradeShopCards` отключается автоматически — можно удалить из StarterGui.
- Карточки островов — вертикальные.

## Старые сохранения
- `Economy.Version = 3`: деньги/сейф/слайм ×0.0125, уровни веток обрезаются под новые цепочки.
