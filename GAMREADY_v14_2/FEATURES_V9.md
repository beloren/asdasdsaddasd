# ФИЧИ v9

Все числа — в `src/shared/Config.lua` (поиск по «v9»).

## Что сделать в Studio

1. Rojo-синк.
2. В Command Bar вставить **весь** `tools/BuildAllUI.lua` → Enter. Это ОДИН скрипт, который собирает весь UI: HUD, инвентарь/хотбар, уведомления, магазины, квесты, награды, престиж, жеоды, банк, коллекцию, мини-игры, бой и т.д. Внутри — те же отдельные билдеры из `tools/`, каждый в своей защищённой функции: ошибка одного не мешает остальным, в конце печатается отчёт ✔/✘.
3. `BuildAllUI.lua` сгенерирован из отдельных билдеров. Поменял отдельный — перегенерируй: `python3 tools/_gen_build_all.py`.
4. Удалены старые билдеры: `BuildSkinUI.lua`, `BuildUpgradeShopCards.lua`, `BuildGeodeOpenCountMenu.lua`, `BuildMutationBookCrystalsTab.lua`.

## 1. Сундуки и динамит в инвентаре
`InventoryService`, `GearService`, `InventoryUI.client.lua`, `GearHud.client.lua`
- Лежат в сетке инвентаря и в хотбаре (Uid `gear:<Key>`), слоты рюкзака НЕ тратят. Новое сразу встаёт в свободный слот хотбара.
- Клик / цифра — взять в руку, повторно — убрать. G для динамита работает как раньше.
- Левая панель снаряжения скрыта (прицел, окно лута остались).
- Покупка динамита — уведомление «+N Dynamite 🧨 (M in bag)».

## 2. Свой динамит
`GearService:_explode`, `CombatService:BlastKnock`
- Бросивший тоже улетает в рагдолл. Руда у него НЕ выпадает. Щит и безопасная зона от своего взрыва не спасают.

## 3. Разлёт руды из шахты
`MineService:_ejectOre`
- Случайные точки с минимальной дистанцией между кусками (`EjectLandMinGap`), куча растёт с количеством руды (`EjectLandMaxSpreadSide/Depth`).
- Во время катсцены над каждым куском крупный «1/N» цветом редкости (цена не увеличивается). После катсцены убирается.

## 4. Слитки и руда в руках сохраняют всё
`InventoryService`, `CrystalService`, `IslandService`, `OreCarryPose.client.lua`
- Сохраняются мутации, GIGANTIC, пещера-источник (редкость) и шанс «1/N» — в рюкзаке, при подарке, в печи и в слитке.
- В руках виден настоящий визуал мутаций (оболочки, материалы, частицы), у GIGANTIC — больше размер и подпись.

## 5. Престиж деревом
`Config.Prestige.Branches`, `PrestigeService`, `PerkUiBuilder`, `PerkUI.client.lua`
- Economy: Money → Safe Income → Cart Space
- Fortune: Luck → Mutations → Geode Finder → Treasure Nose

- Следующий узел открывается при `UnlockLevel` (1) у предыдущего; проверяет сервер. Уже купленные раньше уровни не блокируются.

## 8. Коллекция
`MutationBookService`, `CollectionMenu.client.lua`, `Config.Collection`
- Книга по РУДЕ: каждая руда + каждая мутация на ней. Счётчик «найдено/всего».
- За каждое новое — авто-награда: 3% тележки (руда) / 5% (мутация), минимум $25.
- Старый прогресс перенесён без наград. Старая книга считала по пещерам, поэтому находка засчитывается самой частой руде той пещеры — часть записей откроется заново с маленькой наградой.
- Окно в новом стиле.

## 9. Свои окна — свой стиль, у каждого свой билдер
Общего модуля стиля нет — каждый билдер самостоятельный и выглядит по-своему:
- `PerkUiBuilder` — престиж: «звёздная ночь» (индиго, золотая кайма, узлы-звёзды, линии-созвездия).
- `GeodeUiBuilder` — жеоды: «аметистовая пещера» (тёмный камень, аметистовые грани, сколотая вкладка). Хранилище, покупка, вскрытие, меню «сколько открыть».
- `BankPodiumUiBuilder` — подиум банка: «изумрудный сейф» (зелёная броня, заклёпки, золотая окантовка с бликом, полоска «💰 +$X/MIN»).
- `CollectionBookUiBuilder` — коллекция: «музей кристаллов» (сине-бирюзовый зал, витрины-ячейки, латунная табличка, вкладки-медальоны).
- `BoulderGameUiBuilder` — добавлена карточка дропа «каменоломня» (каменные плашки с золотой кромкой, монеты).
- Общий запуск — `tools/BuildAllUI.lua`.
