# ТЕЛЕЖКА v12 — упаковка вместо кнопки спавна

Полная переделка того, как тележка появляется у игрока. Старое поведение
(«тележка выдаётся сама при заходе» + физическая кнопка «Spawn New» у парковки)
удалено целиком.

## Новый жизненный цикл

1. **У нового игрока тележки нет вообще.** Ни в мире, ни в рюкзаке.
2. **Первая тележка покупается у НПС прокачки за 0.** Карточка ветки Cart
   показывает «GET IT FREE» / кнопку «📦 GET YOUR CART». Покупка не тратит шаг
   `Config.CartChain` и не трогает деньги — она поднимает флаг владения.
3. **Выдаётся УПАКОВКА** — предмет рюкзака/хотбара (иконка 🛒).
4. **Взял упаковку в руки** — она поднимается **над головой**, как кусок руды,
   с подписью «CART PACKAGE · LV N». Видна всем игрокам, не только владельцу.
5. **Появляется предпросмотр** — полупрозрачный призрак настоящей тележки
   там, куда целится игрок: **зелёный** если поставить можно, **красный** если
   нельзя (с причиной строкой внизу экрана). Призрак всегда развёрнут **лицом
   к игроку** — видно заранее, какой стороной тележка встанет.
6. **Поставил** — тележка появляется крошечной и **резко раздувается**
   до полного размера с перелётом («надувается»).
7. **Улучшил тележку:**
   - тележка **стоит в мире** (или в руках) → апгрейд применяется **прямо на
     ней**: пересборка на том же месте + та же надувная анимация, а камера
     продавца летит к ней (штатная катсцена улучшения);
   - тележки **нет** (лежит упаковкой) → игрок просто получает новую упаковку,
     катсцена пропускается сразу. Упаковка **не хранит тир**: тележка
     собирается по текущему тиру в момент постановки.

**Инвариант:** у игрока с купленной тележкой всегда ровно одно из двух —
тележка в мире **или** упаковка в рюкзаке. Двух тележек быть не может.

## Что делать, если тележку потеряли

Кнопки «Spawn New» больше нет — она стала лишней. Вместо неё:

| Что случилось | Что происходит |
|---|---|
| Упала в бездну | Упаковка возвращается через `RestoreDelay` (8 с) |
| Сгорела по таймеру простоя | Упаковка возвращается |
| Гоблин утащил в лагерь | Упаковка возвращается |
| Угнал другой игрок | Ничего: тележка жива, она у вора. Упаковка придёт, только когда та окончательно исчезнет |
| Перезаход в игру | Тележка в мире не сохраняется между сессиями — на заходе выдаётся упаковка |

## Настройки — `Config.CartPackage`

| Поле | Смысл |
|---|---|
| `MaxDistance` / `MinDistance` | 34 / 2.5 — дальше/ближе этого от игрока ставить нельзя |
| `MaxHeightDifference` | 16 — насколько земля может быть выше/ниже игрока |
| `DefaultDistance` | Куда падает превью, если игрок целится в небо |
| `MaxSlope` | 50° — страховка от отвесной стены под центром |
| `MaxGroundSpread` | 5 — допустимый **перепад высот** под тележкой |
| `GroundGap` | 0.9 — на сколько тележка встаёт **выше** земли перед оседанием |
| `ClearanceShrink` / `ClearanceHeightFactor` | Насколько коробка проверки уже и ниже самой тележки |
| `Settle.Seconds` / `Responsiveness` | Удержание вертикали, пока тележка садится |
| `OwnPlotOnly` | `false` — ставить можно где угодно на проходимой земле. `true` — только на своей базе |
| `PreviewOkColor` / `PreviewBadColor` | Цвета призрака |
| `Inflate.StartScale` / `Duration` / `Overshoot` | Параметры надувания |
| `RestoreDelay` | Через сколько секунд возвращается упаковка после потери |

## v12.1 — почему превью краснело почти везде

Первая версия проверки была слишком строгой и её пришлось переделать:

| Было | Стало |
|---|---|
| **Один луч** в точку прицела, уклон по нормали этой точки | **Девять лучей** по всей площади тележки; ровность считается по перепаду высот между ними, а не по нормали случайного камешка |
| Нужно было попадание в одну точку | Достаточно, чтобы отозвалась **треть** замеров — можно ставить на краю площадки, на мостике, на узкой полке |
| Уклон 32° | Перепад высот до 5 стадов + страховочные 50° под центром |
| Коробка пересечений **раздута** (габариты + 0.6) — цепляла стены и бордюры | Коробка **ужата** и приподнята; всё, верх чего ниже дна тележки, — это пол, а не препятствие |
| Любая коллизия = отказ | Незаякоренная мелочь (руда, ящики, обломки) не мешает — тележка её растолкает. Блокирует только статика, персонажей нет в расчёте, и другая тележка |
| Тележка садилась впритык к земле — на кочке колесо тонуло в геометрии | Встаёт на `GroundGap` **выше** земли и **оседает сама**, удерживая вертикаль временным `AlignOrientation` (`_settleUpright`) |

## Модели

Кода править не нужно — всё подхватывается по имени из `Assets`:

- `CartPackage_Tier1..9` — своя коробка под конкретный тир (необязательно);
- `CartPackage` — одна общая коробка на все тиры;
- ни того, ни другого нет → строится картонный ящик-плейсхолдер с лентами.

Формат как у руды: голый `BasePart` **либо** `Model` с `PrimaryPart` /
деталью `Root`. Всё внутри (наклейки, партиклы) сохраняется.

Призрак предпросмотра — это **та же модель `Cart_TierN`**, которую построит
сервер, так что любая кастомная тележка появится в превью сама.

Маркер `CartButtonMarker` в шаблонах участков и ассет `RespawnButton` больше
не используются. Можно удалить, но оставленные ничего не ломают.

## Миграция старых профилей

Поля `CartUnlocked` в старых сейвах нет, и без миграции все действующие
игроки остались бы без тележки. Поэтому профиль с любым прогрессом
(купленный апгрейд, ребёрт, пройденный гайд, >120 с в игре) автоматически
считается владеющим тележкой и получает упаковку на первом же заходе.
Покупать заново ничего не нужно.
